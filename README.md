# Invumo

Invumo is a streamlined, multi-tenant quotation and invoicing SaaS.

> Anything that does not help the user create, send, manage, or get paid for an invoice probably should not exist.

This repository contains the formal product documentation, application code, tests, and deployment assets. Current implementation status is maintained only in the development tracker.
